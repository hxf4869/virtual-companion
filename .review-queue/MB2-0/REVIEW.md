## 总则（适用于所有页面，实现时视为选定图的一部分）

1. **版式以浅色图为准，深色图只作配色参考。** 多页浅深两版的结构不一致（剧情列表标题位置、舞台 A 的 NPC 与行动排布、酒馆列表图标配色、收藏卡片结构、状态卡字段）。
   实现同一套版式，深色只换语义 token。
2. **图只定版式与层级，字段、文案与数据以代码和 DESIGN 为准。** 图中的字段名、示例数值与条目数量不构成需求；缺失或多出的字段按电脑端同功能页面与 API 契约处理。
3. **生成偏差不作实现要求**：同一角色在不同图中长相不一致、模板 / 用途 / 用量行上的多余角色头像、局部装饰与示例文本。
4. **统一控件**（用 Ionic 组件实现，样式映射 DESIGN token）：
   - 分段控件统一为白色玻璃滑块（如 `memory-favorites` 浅色版），不用实心强调色滑块；
   - 二级页标题统一居中、左侧 44 玻璃返回；右侧操作用玻璃胶囊或强调色“保存”，同一类页面一致；
   - 布尔设置一律用开关，不用勾选框；
   - 列表行的次要 / 危险操作用左滑（`IonItemSliding`，§17.3 规格），点行进入主操作；不在每行堆放按钮；
   - 用途、模板、渠道等非人物条目用 30px 彩色图标块（§17.3 设置分组规则），不用角色头像。
5. **剧情页浅色模式底色用蓝青极光**（§17.3“剧情页：深蓝青极光”在浅色下取同色相的浅色），不用粉色极光。
6. **每页实现截图须与选定图并排提交**（计划第 5 节第 4 点），差异逐项说明来源（总则 / 本页要求 / 组件限制）。
