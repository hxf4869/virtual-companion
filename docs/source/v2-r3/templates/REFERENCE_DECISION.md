# 模块复用记录模板

此模板的一行或一个小节即可加入统一复用清单，不必每次单独建文件。

| 字段 | 内容 |
|---|---|
| 当前需求 | 用户实际要完成的行为 |
| 已有实现 | 本仓库代码 / 依赖是否可扩展 |
| 主要候选 | 少量相关项目或模块，不凑数量 |
| 一手资料 | 官方规范、源码路径、固定commit |
| 实际能力 | 读到 / 跑到什么，哪些仍未知 |
| 许可与依赖 | 主项目和运行链分别核验 |
| 采用方式 | 直接依赖 / 扩展 / 服务接入 / fork / 许可内复用 / 设计参考 / 自研 |
| 具体缺口 | 若自研，已有方案为何不满足 |
| 最小验证 | 一个能暴露适配问题的案例 |
| 结果 | 采用 / 未采用 / 待运行；证据和限制 |

选型足够明确后进入实现；同一版本可复用此记录。只有改变已确认产品目标或需要新的外部授权才找用户讨论。
