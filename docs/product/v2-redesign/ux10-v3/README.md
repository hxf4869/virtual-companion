# UX-10 双端组件样板

[DESIGN.md 第三版](../../../../DESIGN.md)的可操作样板，保留原版 Apple 应用语法与手机交互。
当前不是新的客户端，也不进入 SillyTavern 的生产加载链。

在仓库根目录运行：

```sh
python3 docs/product/v2-redesign/ux10-v3/serve.py
```

打开 http://127.0.0.1:18794/ 。可切换组件、模型、语音、身份验证，电脑 / 手机和明暗；
宽度选项覆盖 360 / 390 / 430、768 / 1024 / 1440。原尺寸入口保留当前视图参数。

- 组件：按钮、输入、选择、复选框、开关、滑杆、分段、菜单、编辑 / 确认 / 验证窗、提示、列表、阅读、空与加载。
- 模型：当前 `page.js` 的供应商、用途绑定、模型配置、高级字段及共享影响 / 保存交互；通过页面下方入口可直达三层。
  共用影响出现时滚入可见范围并聚焦确认动作，保留原有确认后保存的流程。
- 语音：当前全局 / 关系渲染函数；桌面分栏与紧凑声音窗，手机原版 Sheet、拖动与完成。保存结果走同一提示组件。
- 身份验证：紧凑原生 dialog，初始焦点、Tab 循环、Enter、Esc、等待占位、关闭清理与焦点恢复。

全部数据为合成示例。浏览器请求由 `fixtures.js` 在本机内存中模拟；没有真实账号、密钥、密码或服务地址。
输入不会写入业务数据；试听只演示交互状态，不调用语音服务。不会调用真实模型、付费接口或生产认证。
原选型记录不读取或覆盖。当前手机网页属于 ST Web，旧 uni-app 已按 W15 退役；本样板没有交付 App / iOS 包。

`serve.py` 只监听回环地址，静态提供本目录和固定扩展目录。模型控制器的状态仅在预览 HTTP 响应中暴露，
不改产品源文件、不增加后端端点。规范值与样板布局集中在 `preview.css`，颜色 / 材质和交互直接使用现有公共 UI。
原版聊天、角色、陪伴和剧情仍见[原交互原型](../prototype.src.html)。

本轮截图与检查记录放在已忽略的 `.review-queue/UX-10/v3/`，只保留一份最终版本；
失败诊断留初轮 JSON，确认后不累积重复截图。完整产品流程、真实语音、真机和 App 验收不由样板检查替代。
