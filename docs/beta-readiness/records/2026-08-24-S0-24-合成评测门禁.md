## 固定评测边界

| 项目 | 有效值 |
|---|---|
| profile / policy | `e2e-synthetic-v1` |
| ReleaseGate | 启动与结束均为 `SYNTHETIC / eval=false / e2e-synthetic-v1` |
| Provider | 回环 `e2e-openai` / `e2e-model`，虚拟 token 不离开本机 |
| 超时 | connect 1s / first token 2s / total 3s |
| 数据 | 隔离 PostgreSQL + 固定合成账号，测试后销毁 |
| 编排 | `bash scripts/dev/synthetic-eval.sh` |

该模式拒绝 `E2E_BASE_URL` 与 `E2E_REUSE_STACK=1`，强制启动新的
OrbStack 隔离栈，避免把合成评测误发到外部环境。真实浏览器纵切期间，
该临时数据库按预期短暂进入 `BETA/eval=true/e2e-synthetic-v1`，teardown
检查后恢复上述安全终态并销毁；这不触碰真实环境 gate。本次未读取真实
Provider 凭据、未发起真实 Provider 请求，因此不产生额外供应商费用。
