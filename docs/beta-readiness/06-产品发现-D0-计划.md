# 06 · 产品发现（D0）执行计划

对应需求 §7.2「产品发现基线」、§24.1「D0：产品发现」、§2.4「产品发现阶段」。
**状态：Agent 代拟草案，Owner 复核后执行。** D0 是进入受控 Beta 前的门禁
（TODO「D0 产品发现」节）：不达线优先调整人群或价值主张，不默认进 Beta；
不阻塞代码轮。

## 1. 目标与要回答的问题

确认三件事（§24.1）：

1. 目标人群是否真实存在；
2. 核心价值是倾诉还是记忆（或都不成立）；
3. 用户是否会主动第二次回来。

访谈必须覆盖的问题域（§2.4.2，提纲见 §4）：

- 最近一次想倾诉但没有找人的具体时间、触发和后续；
- 当时使用了什么替代方案；不找现实联系人的原因；
- 「先倾听 / 给建议 / 记住上次 / 形成关系」的优先级排序；
- 哪些内容绝不允许长期记忆；
- 模型变笨、服务不可用时能接受什么退化；
- 对 AI 明示、记忆确认和数据删除的真实反应；
- 对价格、额度和等待的容忍度；
- 对轻度亲昵称呼、暧昧和浪漫模式的边界。

## 2. 招募条件

### 2.1 纳入标准

- 年满 18 周岁（项目红线：成年验证前置，D0 不接触未成年人）；
- 首轮 15～20 名有效访谈对象；
- 其中 **至少 12 名**最近一个月真实出现过「每周一次以上」的晚间倾诉、
  记录或使用聊天机器人场景（§2.4.1 硬性比例）；
- 能在 7 天内完成一次回访（回访意愿本身是退出条件之一）。

### 2.2 排除标准

- 未成年人；
- 自述正处于心理危机或依赖专业治疗中的人群（访谈不是服务，不替代专业
  支持；如访谈中出现危机信号，按 [01-人工处置-runbook.md](01-人工处置-runbook.md)
  的求助资源口径回应并终止该场访谈）；
- 与团队有直接利益关联、可能迎合回答的亲友圈（§2.4.1：不得只访谈朋友中
  「对 AI 感兴趣」的人）。

## 3. 筛选问卷（≤10 题）

| # | 题目 | 用途 |
|---|---|---|
| 1 | 你的年龄段？（18–24 / 25–30 / 31–35 / 36+ / 不便说） | 成年甄别 + 人群校验 |
| 2 | 最近一个月，你有多少个晚上有过「想说说今天的事但没找人」的时刻？（≥每周1次 / 偶尔 / 几乎没有） | 核心场景甄别（§2.4.1 的 12 名门槛） |
| 3 | 那种时刻你通常怎么做？（写日记 / 刷手机 / 找朋友 / 聊天机器人 / 忍着） | 替代方案画像 |
| 4 | 你用过聊天机器人/AI 对话产品吗？（经常 / 试过 / 没有） | 经验分层 |
| 5 | 如果一个应用能记住你上次说过的事，你的第一反应？（方便 / 有点可怕 / 看它记什么） | 记忆价值与边界信号 |
| 6 | 以下哪件事你最不在意 AI 做？（多选：记住偏好 / 主动找你聊 / 给建议 / 陪聊） | 价值排序预筛 |
| 7 | 你能接受的每日使用时长上限？（≤15 分钟 / 30 分钟 / 更长） | 低压力定位校验 |
| 8 | 最近一周方便的时间段？（用于约访） | 排程 |
| 9 | 是否愿意在 7 天后参加一次 15 分钟回访？（愿意 / 再说 / 不愿意） | 回访意愿预筛（退出条件输入） |
| 10 | （甄别）你是否年满 18 周岁并同意访谈仅用于产品研究？（是/否） | 合规门槛 |

> 问卷工具与数据回收方式 `[待填]`。回收数据只做筛选，不入仓库、不入业务库。

## 4. 访谈提纲（半结构化，每场 45–60 分钟）

开场声明（照读）：「今天是产品研究访谈，不是服务体验；没有对错答案，
你的负面评价对我们更有用；内容仅用于研究，录音/笔记方式 `[待填]`，
可随时暂停或退出。」

### 4.1 场景还原（15 分钟）

1. 「请回想最近一次晚上想说说心事、但最后没找人的那次——当时发生了什么？」
   （追问：几点？什么触发？之前类似情况多久一次？）
2. 「后来你做了什么？」（追问到具体行为：写下来？刷手机？发给谁？）
3. 「为什么没找现实里的人？」（追问：是没人、怕麻烦别人、还是说了没用？）

> 提问纪律：一律问「上一次真实发生」的过去式问题，禁止问「你会不会愿意
> 用一个 AI 来倾诉」这类诱导性假设题。

### 4.2 价值排序（10 分钟）

4. 出示四张卡片：「先听我说完」「给我具体建议」「记住我上次说过的事」
   「像一个熟悉的朋友」，请排序并说明理由。（对应 §7.2 四类价值排序）
5. 追问：「如果只能保留一个，你删哪个？」

### 4.3 记忆边界（10 分钟）

6. 「如果一个应用要长期记住你说过的话，哪些内容是你绝对不允许它记的？」
7. 出示记忆确认流程示意（候选→确认→可修改→可删除→看来源）：「这个流程里
   哪一步你会不放心？」
8. 「如果发现它记错了、或者记住了你已让它删掉的事，你会怎么做？」

### 4.4 退化容忍（10 分钟）

9. 「如果某天它明显变笨了/答非所问，你会？」（追问：容忍几次？）
10. 「如果服务临时不可用，只允许你记录文字、看旧对话、管理记忆，可以接受吗？」

### 4.5 边界与身份（10 分钟）

11. 「它应该在聊天里明确告诉你它是 AI 吗？以什么方式？」
12. 「轻度亲昵称呼（比如昵称）可以接受吗？浪漫/暧昧内容呢？」
    （只记录边界，不引导）
13. 「这类服务收费/限量/排队，你能接受哪种？」

收尾：「还有什么关于『晚上想说话』这件事我没问到、但你觉得重要的？」

## 5. 原型体验脚本（≥10 人）

载体：现有 H5（测试账号），全程明确标识「演示/技术测试」。§2.4.3 要求的
三个低成本原型映射到现有页面动线：

| 原型（§2.4.3） | H5 动线 | 观察点 |
|---|---|---|
| 倾听型对话 | 登录 → 创建角色 → 新会话 → 用 LISTEN 模式聊 3 轮 → 切 DISCUSS 再聊 2 轮 | 用户是否主动倾吐；切模式时是否察觉差异；先听 vs 先建议的偏好 |
| 记忆确认 | 聊后打开记忆页 → 查看待确认候选 → 确认一条/修改一条/拒绝一条 → 查看来源 → 删除一条 | 是否理解候选机制；删除后是否追问「真的删了吗」；对来源展示的反应 |
| 模型降级 | 服务切换 ZERO_LLM/受限文案（测试开关）→ 观察受限提示与安全求助入口 | 是否理解发生了什么；是否接受「记录模式」；信任变化 |

体验后立即记录（10 分钟）：最惊喜的一点 / 最别扭的一点 / 7 天内是否愿意
再来（愿/否/犹豫）。**不得把人工回复伪装成自动 AI**（§2.4.3）；不收集
不必要的真实敏感信息。

## 6. 二次回访邀请模板（7 天内发送）

> 上次谢谢你陪我聊产品想法。我们根据你的反馈改了一些地方，想再占用你
> 15 分钟看看现在的版本，听听哪里变好了、哪里还是不行。时间你定；如果不
> 方便，直接忽略这条消息就好，不会有任何影响。`[发送渠道待填]`

要求：平实、无情绪施压、明确可忽略（需求 §24.1 口径）。

## 7. Go / Pivot / Stop 判定（§2.4.4，Owner 复核）

同时满足以下五条 → **Go**（进入受控 Beta 准备）：

1. ≥60% 有效访谈对象把「低压力倾诉」列入价值前两位；
2. ≥50% 把「准确延续上次内容」列入前两位；
3. 完成 ≥10 次原型体验的对象中 ≥6 名愿意 7 天内再次体验；
4. 未出现多数用户强烈排斥 AI 明示或可控记忆机制；
5. 团队能明确写出一个主场景和一个不做场景（写入 ADR）。

Pivot / Stop 路径（§2.4.4）：

- 「想聊天」成立但「长期记忆」价值弱 → 记忆缩减为会话摘要；
- 用户主要需要专业建议 → 停止把产品定位成普通陪伴；
- 只有强浪漫关系才能产生兴趣 → 重估合规与运营能力，不扩大首版范围；
- 多数条件不达且无清晰 Pivot → **Stop**，决策写入 `docs/decisions/`（ADR）。
