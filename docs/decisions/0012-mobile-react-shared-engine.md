# ADR-0012：手机端改为与电脑端共用 React 代码与独立引擎

- 状态：Proposed（待 Owner 批准；批准前不实施 MB2-2 及之后的条目）
- 日期：2026-11-06
- 决策人：Owner
- 替代：ADR-0011 第 1、2 节（uni-app 界面 + 同源隐藏 ST 引擎、ST 视图）与第 4 节中“uni-app App 用 web-view”的壳选型
- 保留：ADR-0011 第 3 节（`/m/` 同源入口、不新增暴露面）、第 5 节（通知与后台）、第 6 节（语音通话与来电）、
  第 7、7.1 节（设计与主题扩展点）、第 8 节（范围与授权）
- 关联：ADR-0009、DR2 电脑端重建（`docs/superpowers/specs/2026-11-04-desktop-react-rebuild-design.md`）、
  实施计划 `docs/planning/2026-11-06-mobile-react-rebuild-plan.md`

## 背景

ADR-0011 选定的路线 D（独立 uni-app 界面 + 同源隐藏 ST 引擎）在 `mb-mobile` 上完成了 MB-0–MB-5、MB-7–MB-10 的 H5 部分，
MB-6 Android 壳未实施，分支未合并。此后电脑端完成 DR2 重建并于 2026-11-06 合入 main（`f502c4b9`）：

- 电脑端是单一 React 应用（`integrations/sillytavern/desktop-ui`），不运行完整或隐藏的 ST 页面。聊天、复杂卡（Tavern Helper /
  EJS / MVU）、提示词组装与 Slash 由 `extension/vc-model-settings/desktop/standalone/`（锁定上游源码生成的独立引擎）执行，
  消息与变量统一经 Session / F2 / CAS 写入。
- 电脑端已有四档布局（`narrow` < 744 / `compact` / `regular` / `wide`）、主题与角色覆盖（UX-35）、
  以及手机端没有的大量页面：剧情舞台、酒馆九类设置、收藏 / 提醒 / 日记、表情包、建议回复、陪伴状态、使用量与本地模型等。

继续 uni-app 路线意味着：电脑端每个功能都要用 Vue 再实现一次；手机依赖 `/native/` 完整 ST 宿主作为第二套引擎
（冷启动 3.8–5.2 s、额外 10–20 MB 堆，见 MB-0），复杂卡、剧情与酒馆配置只能切到冻结的旧 ST 手机布局（“ST 视图”）。
Owner 2026-11-06 决定手机端重做，可接受大面积调整。

## 决策（建议）

1. **一套 React 代码，两个入口。** 手机界面在 `desktop-ui` 工程内新增手机入口与手机壳，与电脑端共用数据层（`src/data`）、
   会话桥（`src/runtime/session-bridge.ts`）、设计 token、基础组件和各功能的业务逻辑；只有壳层、导航和需要手机交互的
   展示组件分开实现。`/m/` 提供手机构建产物，`/` 与 `/desktop/` 仍是电脑端。
2. **一个引擎。** 手机直接使用电脑端的独立引擎与卡片运行模块，不再加载隐藏 ST 页面，不再有“ST 视图”。
   复杂卡在消息内或全屏卡片页中由 `standalone/cards` 渲染；剧情与酒馆配置使用 React 页面的手机布局。
3. **uni-app 不再作为界面框架。** `mb-mobile` 的 Vue 代码不合并，只作为功能与交互参考；其中与框架无关的语音、
   通话、来电逻辑可按需移植。`mb-mobile` 上的后端与契约改动（来电、MDL-2 工具预算等）单独迁移到 main。
4. **Android 壳改为薄原生壳加载 `/m/`。** 首选 Capacitor（Android 工程入库、本地离线构建），壳的职责与边界照 ADR-0011 第 4 节。
   壳选型以 MB2-1 的 Spike 结果为准：需在 MuMu 模拟器上验证 Cookie 保持、麦克风、软键盘、返回键、前台服务保活 30 分钟、
   本地通知快捷回复回传和系统分享，并核对插件许可；任一项不通过，回到本 ADR 修订，不在壳里补业务逻辑。
5. **`/native/` 的去留。** 手机 React 端达到功能对齐并经 Owner 验收后，评估移除 `/native/` 原生手机宿主
   （ADR-0011 后续清理项）。在此之前保留，不改其行为。

## 后果

- 新功能只写一次；手机端与电脑端行为一致，两端同一份聊天与同一条生成链（ADR-0009 §2 不变）。
- 手机首屏需要单独的性能预算：电脑端最大的三个 JS 包合计约 2.3 MB（gzip），手机入口必须按路由拆分并延迟加载引擎。
- DESIGN.md 第 17 节改为“手机界面”（不再限定 uni-app），数值沿用；第 17.3 节“酒馆条目打开 ST 视图”等描述随实现修订。
  MB-1 未覆盖的页面（剧情舞台、酒馆配置、收藏 / 提醒 / 日记等）需先出图并由 Owner 选定。
- 新增依赖（Capacitor 及插件、Android 构建工具）按 ADR-0009 §3 的条件引入并登记许可清单。

## 不授权

iOS、上架、系统推送服务、云打包、任何费用与部署；合并 main 与部署仍按 AGENTS.md 另行指示。
