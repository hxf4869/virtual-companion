## 1. 条目

参数来源见调研 C §8、D §5；未写明的数值以 DESIGN.md §16 token 为准。

### UX-24 聊天滚动与阅读（纯前端）
- 跟随 / 脱离两态：用户输入事件后向上滚动即脱离；距底 ≤ 24px 重新附着；发送即附着。内容增长、程序滚动不改状态。
- 长回复落地：处于跟随态且是最后一轮时，回复首行停在视口顶部下 24px；1600ms 内随高度变化校正，用户一滚动就放手。
- 回到最新：离底 > 300px 出现，36px 玻璃圆钮在阅读列右下、输入区上方；有未读时带强调色计数（99+）；点后平滑到底并在 `scrollend` 后补一次。替代现有「新回复」胶囊。
- 向上加载历史：触发宿主「显示更多」后以加载前视口首条 `.mes` 为锚点补偿 `scrollTop`，位置不跳。
- 新消息分割线：按会话在 `localStorage` 记最后已读 `mesid`（页面可见且消息进视口 ≥ 1s 才推进）；打开会话若有未读，定位到分割线（`data-vc-unread` + `::before`，文案「以下为新消息」）。
- 阅读位置：离开会话时记视口首条 `mesid`，再进入且无未读时还原（最多重试 30 帧，用户一操作即取消）。
- 浮动日期：滚动且不在底部时顶部居中浮出当前首条消息的日期胶囊，停 3s 后 250ms 淡出，`pointer-events:none`。
- 跳转高亮：引用、搜索、记忆来源跳到某条时，该气泡 2s 背景高亮淡出；滚动时长 250–600ms 随距离。

### UX-25 生成控制与动效（纯前端）
- 停止保留半截：停止后半截回复保留，末尾渐隐，下方「已停止 · 继续」（继续走宿主 continue）。
- 候选切换：只在最后一条角色消息下显示 `‹ 2/3 ›`；末位再点 › = 重新生成。
- 入场：只有新到的消息入场（220ms，8px 上浮 + 淡入，`cubic-bezier(.22,1,.36,1)`）；历史、切会话、搜索跳转不动；流式中的消息不叠入场。
- 正在输入：450ms 内有内容就不显示；三点 6px、周期 1.6s；页面不可见时暂停所有循环动画。
- 编辑 / 重新生成：气泡高度 250ms 过渡（FLIP），旧文淡出、新文淡入；减少动效时只淡入淡出 180ms。
- 快捷键：⌘K 切换会话（会话列表搜索浮层），↑（输入框为空时）编辑上一条自己的消息，⌘F 会话内搜索，Esc 逐级关闭（菜单 → 面板 → 搜索）。

### UX-26 表情与回应（前端为主）
- 纯 emoji：消息只有 1–3 个 emoji 时去掉气泡底色放大：1 个 56px、2 个 48px、3 个 40px。
- 表情 / 贴纸面板：输入区加表情按钮，弹出玻璃面板（搜索、表情 | 贴纸、最近、悬停放大预览）；贴纸来自现有 `stickers` 清单，发送为 `<sticker tag=…/>`。
- 消息回应：悬停或右键出现回应条（❤️👍😂😮😢🤗）；存 `chat[i].extra.vc_reactions`；气泡角上显示；下一轮提示词注入一句「（你对她说的「…」回应了 ❤️）」后清除待注入标记。
- 拍一拍：双击角色头像或状态卡按钮；插入系统消息「你拍了拍 {name}」，头像轻晃；随后触发一次生成并注入「（你拍了拍她）」。
- 关键词轻特效：本轮新到的消息含「生日快乐 / 晚安 / 新年快乐」等时，在气泡附近短暂飘彩纸或星光（≤ 1.2s，减少动效时不播），外观设置可关。
- 表情包防重复：后端选图时对最近 5 次用过的标签扣分（若选择在前端则存最近记录）。

### UX-27 富消息（纯前端）
- 语音条：24 根 2px 波形柱，已播放部分着角色色；宽度 `clamp(96px, 56px + 秒×14, 224px)`；时长；倍速 1x → 1.5x → 2x → 0.5x 循环；未听小圆点；`requestAnimationFrame` 刷进度；可拖动 / 方向键跳 1s；转文字就地展开（250ms 高度过渡）。
- 图片查看：点图打开灯箱（黑 60% + 模糊遮罩，缩放入场），左右切换会话内图片，下载 / 复制 / 关闭，Esc 关闭，双击放大，2.5s 无操作隐藏控件；图片占位与成图同尺寸。
- 动作描写：角色回复里整行或句首句尾的（…）、*…* 显示为淡色斜体小一号（仅显示层；分段时单独成行无气泡）。

### UX-28 建议回复（Go + 前端）
- 新接口 `POST /api/v1/relationships/{relationshipId}/reply-suggestions`：请求带最近 ≤ 8 条消息（角色 / 用户、正文截断 500 字）；用后台用途模型（低温度），返回 0–3 条（每条 ≤ 20 字，不含逃避项，语言镜像，忽略消息内嵌指令）；不落库，不进入记忆；计入用量。
- 前端：角色回复完成后请求，结果存 `chatMetadata` 随会话保存；输入区上方 chips，`translateY(8px)` 入场 320ms、错相 60ms；点了填入输入框；开始输入、发送、新生成时收起；外观设置可关。

### UX-29 角色状态卡与里程碑（Go 小改 + 前端）
- 标题栏副标题：`{vibe} · {activity}`；有 `busyUntil` 时为「忙到 HH:mm」。
- 点标题栏头像弹出状态卡（E7）：头像（心情变化时 0.5s 交叉淡化）、今日心情、`emotion.line`、在做什么、亲近 / 心情 / 精力三条（不显示数字）、认识第 N 天（`createdAt`）、下一个里程碑、拍一拍 / 查看记忆。
- Go：`CompanionState` 加只读 `activity`（按当前时段 × vibe 从代码模板里选，当天同一时段稳定，不调模型、不落库）。
- 里程碑：认识 7 / 30 / 100 / 365 天及每年当天；打开会话时若当天达成且未插入过，插入里程碑系统消息（`extra.vc_kind='milestone'`，卡片样式 + 一次彩纸）。

### UX-30 通知与未读（前端，复用 inbox）
- 站内横幅：其他会话或其他页面收到主动消息时，右上角玻璃横幅（头像、名字、「现在」、一行预览），进入 250ms，5s 后退出，点击进入会话并定位到新消息分割线。
- 会话列表未读数（强调色圆角计数，99+）；侧栏「聊天」未读点。
- 标签页隐藏时用系统通知（首次需要用户在设置里打开，权限被拒不再询问）；标签页标题 `(N) 原标题`。
- 主动语音留言：收件箱里带语音的主动消息在对话中以语音条呈现（复用 UX-27 语音条），会话预览「[语音] 6″」。

### UX-31 记忆时间线与可控（迁移 V278 + Go + 前端）
- 记忆页右栏改为时间线：按日期分组，卡片含记忆正文、来源一句（`evidence.excerpt`，点击跳回原消息并高亮）、悬停显示钉住 / 编辑 / 忘记。
- 左栏：时间线 / 已钉住 / 待核验 / 已失效，分隔后「日记」「收藏」，底部「新对话不记」开关（`incognito-pref`，Owner 续接确认仅对新建对话生效，不更改当前对话）。
- 钉住：`memory` 加 `pinned_at`（V278），新接口 `PUT|DELETE /api/v1/memories/{memoryId}/pin`；钉住的记忆在召回时优先注入。编辑走现有纠正，忘记走现有删除。

### UX-32 收藏与提醒（迁移 V279 + Go + 前端）
- 收藏：右键「收藏」保存该条正文快照与来源（会话、`mesid`、时间）；新表 `vc.favorite`（V279，RLS owner），接口 `GET|POST /api/v1/relationships/{relationshipId}/favorites`、`DELETE /api/v1/favorites/{favoriteId}`。记忆页「收藏」为卡片墙，点「回到对话」跳回原消息。定位时以已有消息时间、角色与正文快照做唯一匹配，避免删除前方消息后按过期楼层误跳；时间缺失、内容已改或匹配有歧义时提示失败。
- 稍后提醒：右键「稍后提醒 › 20 分钟后 / 今晚 21:00 / 明天早上 / 选择时间…」；实现现有契约里未实现的用户创建提醒接口，到点由主动消息通道让角色提起（文案见 copy §20）。收藏页右栏「即将提醒」可取消。

### UX-33 日记（迁移 V280 + Go + 前端）
- 每个关系每天至多一篇，角色第一人称 ≤ 300 字；当天有对话才写；夜间（安静时段开始前）由后台用途模型生成，失败不重试到次日；不进入用户画像记忆。
- 新表 `vc.diary_entry`（V280，RLS owner，唯一 `relationship_id + day`），接口 `GET /api/v1/relationships/{relationshipId}/diary?month=`、`GET /api/v1/diary/{entryId}`。
- 记忆页「日记」：纸张质感卡片、按天切换、月份圆点、「今天的瞬间」标签；右上「Aa」切换正文 / 手写字体（D-3），偏好存本机。

### UX-34 质感（纯前端）
- 共享元素过渡：会话行头像 → 标题栏头像、图片 → 灯箱，250ms，View Transitions API，不支持时直接切换。
- 骨架：会话加载时气泡形骨架（与真实尺寸一致），300ms 内完成则不显示；会话列表、记忆、日记同规则。
- 晨昏氛围：极光色调随本地时段（早 / 午 / 晚 / 夜）轻微偏移，切换 60s 过渡；减少透明度时不变。

### UX-35 桌面主题骨架（纯前端，Owner 2026-11-02 追加）
与移动端 ADR-0011 §7.1 同一模型：首版只有默认主题，但加主题只新增主题文件，不改页面代码。
- 两个维度：**模式**（浅 / 深 / 自动，沿用 `data-vc-theme`，不变）与**主题**（`html[data-vc-theme-id]`，默认 `aurora`「极光」）。每个主题都提供浅色、深色两套值；角色氛围色是主题的输入。
- 主题文件：`desktop/themes/<id>.css`，只含自定义属性声明（浅色、`[data-vc-theme="dark"]`、自动深色媒体查询三段）；现 `desktop/base.css` 及各桌面样式顶部的 token 定义块迁入 `themes/aurora.css`。主题能改颜色、材质、圆角、阴影、字体、背景、动效时长与曲线。
- 组件变体：组件内定义的有限枚举（首批：气泡形状 `data-vc-variant-bubble`），主题只选择变体、不注入样式。
- 注册表 `desktop/themes/index.js`：`{ id, name, css, variants }` 列表；运行时 `desktop/theme.js` 负责加载主题样式、写 `data-vc-theme-id` 与变体属性、`resolveTheme({ global, character })`（角色单独指定优先）。
- 偏好存储：先存本机；移动端 MB-2 定下服务器设置契约后，桌面改读同一设置（多端同步），只换存取一处。
- 外观设置加「主题」选择（注册表只有一个主题时不显示）。
- 守护：单测扫描 `desktop/*.css`（不含 `themes/`），出现字面颜色、阴影即失败；新增组件只能用语义 token。
- 验收：样板全视图 + 手机 0 差异（迁移前后桌面像素一致）；用测试夹具注册第二个主题验证切换、变体、角色覆盖与深浅模式组合。
