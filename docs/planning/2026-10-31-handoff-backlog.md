### UX-10 本轮问题清单

- **P1 手机导航阻断**：隐藏的角色 / 记忆 / 陪伴详情仍命中 `:has(.is-detail)`，底部导航失去点击能力；`vc-ui-shell` 在深色 360 复现点击超时。
- **P1 陪伴状态缺失**：前端读取既有 `companion-state` 被管理桥白名单拒绝，心情 / 情绪提示未接通；三协议浏览器场景实际返回 404。
- **P1 并发来源同步中断语音**：全流程回归中，录音转写已保存但语音未入队，来源同步返回 `400 INVALID_REQUEST`。同步的 CAS 在其他请求已应用更新版本时仍重复读取，三次竞争后返回冲突；现有 HTTP 映射把该冲突表现为 400。现沿用已提交的更新来源状态，保留删除与不可用状态的关闭语义，没有增加重试层。
- **P1 非流式回复未重写**：硬违规回复渲染事件早于宿主解除生成忙碌状态，此时立即点击重新生成被原生入口忽略；受管场景只捕获一次请求。延后至原生生成与保存结束再触发一次，聊天切换、停止或新消息取消旧请求。
- **P1 角色实例归属丢失**：关系接口未返回已持久化的角色引用，角色页只能借用当前聊天的绑定；无当前聊天时，已有两个实例却显示为模板的 0 个实例。由现有关系记录返回可选 `characterRef`，包括尚无聊天文件的实例，不新增表或迁移。
  多实例声音选择同时补齐同名序号，受管场景实际选择并验证当前实例，避免把菜单当作已打开的设置表单。
- **P1 实例选择错误**：记忆与陪伴页把旧宿主预置的 `gentle-listener` 空关系放在首项，默认出现“未命名角色”，偏离当前 ST 角色。
- **P2 返回路径错误**：桌面模型首页“返回设置”关闭后回到聊天，九个酒馆抽屉同名返回入口也只关闭抽屉，设置页未恢复。沿用已有外壳导航事件返回设置，逐个验证抽屉。
  手机连续返回时，旧设置弹层的关闭回调会清掉新弹层引用，360px 整站走查稳定复现两层设置重叠。关闭回调只清理自己的句柄，保留当前弹层引用。
- **P2 模型配置难以找到**：手机模型页先铺开整月各用途用量，供应商与用途绑定被挤出首屏。
