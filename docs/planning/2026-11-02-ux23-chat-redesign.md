# UX-23 桌面聊天改版（即时通讯气泡）

> 2026-11-01/02 Owner 问答定稿。参照图 `.review-queue/UX-23/images/C1-1.png`（主）、C2（右键菜单 / 引用）、C3（搜索）、C4（失败）；
> 调研 `.review-queue/UX-23/research-A.md`、`research-B.md`；QA `.review-queue/UX-22/QA/REPORT.md`。
> 约束沿用 UX-11 实施方案第 1 节与 DESIGN.md 第 12、16 节：**只改桌面（`html[data-vc-layout="desktop"]`），手机像素不变**；
> 不改宿主 `#chat > .mes` 结构、不往 `.mes_text` 子树插节点、不往 `#chat` 插非 `.mes` 节点；不新增后端接口与依赖；文案先写进文案文档。

## 0. 决定

| # | 决定 |
|---|---|
| C-1 | 桌面默认「即时通讯气泡」：双方都是气泡；本机未存偏好时桌面按气泡，外观里仍可切回「铺开」；含 iframe / 卡片脚本 / 图片的富消息与剧情自动按铺开呈现 |
| C-2 | 背景只用极光（不用 ST 背景图） |
| C-3 | 时间：同组只在组尾显示一次；桌面悬停单条时显示该条时间 |
| C-4 | 状态只显示真实发生的：最后一条用户消息下「已发送」→ 生成中「正在输入」→ 回复；不做已读、不加拟人延迟、不画双勾 |
| C-5 | 本轮功能：成组气泡 + 日期 / 间隔胶囊；右键菜单 + 引用回复；草稿保存 + 失败回填；会话内搜索 |
| C-6 | 参照图里不做：电话、在线状态、背景立绘、附件按钮、图片外的消息类型扩展 |

## 1. 规格

### 1.1 气泡与分组（参照 C1）
- 角色气泡：左对齐，底 `--vc-raised`，0.5px `--vc-raised-edge`，圆角 18；用户气泡：右对齐，底 `--vc-accent`，白字。字 17 / 行高 1.5，内边距 10 14，最大宽为阅读列 75%。
- 分组：同一发送者、相邻两条间隔 < 5 分钟为一组。组内间距 4，组间 12；组内相邻侧圆角收为 6（左侧气泡收左角，右侧收右角）；角色头像 32 只在组末气泡旁显示，其余位置留空占位。
- 组尾时间：组末气泡下方 12px 灰字（ink-2）`HH:mm`；悬停单条显示该条 `HH:mm`（同位置，淡入 150ms）。
- 日期 / 间隔胶囊：跨天或与上一条间隔 ≥ 20 分钟时，在该条上方居中显示胶囊：今天 `HH:mm`、昨天 `昨天 HH:mm`、7 天内 `周X HH:mm`、更早 `M月D日 HH:mm`；跨年加年份。胶囊 13px ink-2、底 `--vc-raised`、圆角 pill、上下各 12。
- 实现：数据来自 `getContext().chat[mesid].send_date`；分组 / 胶囊 / 时间写成 `.mes` 上的 `data-vc-*` 属性，由 CSS `::before` / `::after` 用 `attr()` 渲染，**不插 DOM 节点**。在 `CHAT_CHANGED`、消息渲染、删除、swipe、流式结束时重算。
- 角色「本次想起」类系统消息、旁白按原样。

### 1.2 状态与输入中（参照 C1）
- 最后一条用户消息组尾在时间后加「· 已发送」（保存完成后出现）。
- 生成中：`#vc-chat-gen` 在桌面改为阅读列左缘、输入区上方的左对齐气泡：三点动画 + 「正在输入」（文案取 `TYPING_COPY`）；回复节点出现即隐藏。
- 不显示已读、不显示双勾。

### 1.3 右键菜单与引用（参照 C2）
- 桌面右键（`contextmenu`）消息：不再走手机长按的克隆抬起与全屏模糊；被点气泡轻微抬起（scale 1.02 + 阴影），菜单用 `ui/menu.js` 在鼠标位置弹出（避开视口边）。手机长按保持原样。
- 菜单项：引用、复制、朗读（有语音时）、分隔、编辑、重新生成（仅最后一条角色消息）、分隔、删除（红，走确认框）。每项转发宿主原生能力。
- 复制成功：全局提示条「已复制」（QA P2-4）。
- 引用：输入区上方出现引用条（左 2px 强调色竖线、13px「引用 名字：摘要」、≤ 30 字截断、右侧关闭）；发送时消息正文前拼 `> 名字：摘要\n\n`；引用的消息气泡顶部渲染为引用块（左竖线 + 灰字），只改显示，存储保持文本。

### 1.4 输入区与草稿、失败（参照 C1、C4）
- 输入框自增高 1–6 行，清空 / 发送后回到 1 行（QA P1-8）。
- 「+」不再弹宿主黑色原生菜单（QA P1-4）：桌面改为 `ui/menu.js` 菜单，列出宿主 `#options` 中常用项（重新生成、继续、删除消息改走确认框等），危险项走确认框；Esc 关闭。
- 草稿：按会话存 `localStorage`（键含聊天 id），500ms 防抖；发送成功清除；会话列表行显示「草稿：…」（灰）。
- 失败：生成失败时不再出现宿主英文 toast（QA P1-2）；最后一条用户消息组尾显示红色「没有发送成功 · 重试」（重试走原生重新生成）；若用户消息未落地，原文回填输入框。超时 60 秒仍无内容时在 `#vc-chat-gen` 显示「回复较慢，可以继续等或停止」。

### 1.5 会话内搜索（参照 C3）
- 标题栏右侧加搜索圆钮；点开后标题栏变为搜索条：输入框、`n / m` 计数、上下跳转、「完成」。250ms 防抖，范围为当前会话已加载消息；匹配词用浅黄高亮（`mark`，只在桌面），当前匹配气泡描边强调色；Enter 下一条、Shift+Enter 上一条、Esc 退出。
- 高亮不得写入 `.mes_text` 子树：用 CSS Custom Highlight API（`CSS.highlights`），不支持时只描边当前气泡。

### 1.6 其他 QA 遗留（聊天）
- P1-5 「记忆」按钮：桌面改为打开角色面板并滚到「本次想起」，不再出现旧版平白右栏。
- P1-6 768 / 1024 角色面板：不得让对话消失；744–1023 面板以浮层出现且不盖住输入区与标题栏按钮，1024–1179 对话宽 ≥ 560（不够时同 744–1023）。
- P2-2 会话列表行：名字与实例不重复；预览随最新消息刷新；显示时间。
- P2-3 「已停止」与 P1-2 提示统一放 `#vc-chat-gen` 位置。
- P2-6 编辑态：桌面编辑框用本系统输入样式，下方「取消」「保存」按钮可见。
