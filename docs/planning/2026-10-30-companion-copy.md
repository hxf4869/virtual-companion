配套设计：`2026-10-30-companion-humanlike-design.md`。占位符用 `{{...}}`，由程序替换。文案修改只改本文件对应段并同步代码常量。

## 登录后载入（UX-10）

- 状态：`正在打开聊天…`
- 载入超过 20 秒后操作：`重新加载`
- 只重新打开当前入口，不自动重试或要求重复登录。

## 页面验证与重新验证身份（UX-10）

- 验证说明：`保存前，请验证当前账号的密码。`
- 验证中按钮：`正在验证…`
- 宿主页面验证失效：`页面验证已过期，请重新加载页面后再试。`
- 重新验证时会话变更：`登录状态已变化，请重新加载页面后再试。`
- 登录过期：`登录已过期，请重新登录后再试。`
- 仅密码校验明确拒绝时：`密码不正确，请重试。`
- 验证限流：`验证次数过多，请稍后再试。`
- 网络或服务暂不可用：`暂时无法验证身份，请稍后重试。`
- 其他验证失败：`身份验证未完成，请重试。`
- 不自动刷新、重放写入或重新提交密码；草稿留在当前页面。

## 双端组件反馈（UX-10，第 3 版样板）

- 保存成功：`已保存`
- 身份验证完成：`已验证`
- 复制完成：`已复制`
- 删除完成：`已删除`
- 通用操作失败：`没有完成，请重试。`
- 未保存退出标题：`放弃更改？`；后果：`关闭后本次输入将丢失。`；动作：`放弃修改并关闭`
- 删除记忆确认标题：`删除这条记忆？`；后果：`聊天原文仍保留，可能继续用于当前对话。`；动作：`删除记忆`
- 通用记忆空状态：`暂无记忆`
- 本节只在本轮样板先行对齐；产品页面按 UX-10 后续迁移，不据此宣称生产反馈已统一。
- UX-11 起，未保存退出的动作改为下节的 `继续编辑` / `放弃`，替代上面的 `放弃修改并关闭`。

## 桌面改版与交互统一（UX-11，两端共用）

- 未保存退出（页面、弹窗、Sheet 统一）：标题 `放弃更改？`；后果 `关闭后本次输入将丢失。`；
  安全动作（默认焦点）`继续编辑`；危险动作 `放弃`。
- 有修改时出现在保存按钮左侧的文字按钮：`放弃修改`（不再显示 `未保存的修改` 标签）。
- 保存进行中：`保存中…`；手机 Sheet 右上：`完成`。
- 危险确认的通用安全动作：`取消`（默认焦点）；删除记忆确认沿用上节文案。
- 共用影响确认：标题 `同时影响 {{count}} 个用途`；后果 `{{purposes}} 会使用修改后的配置。`
  （purposes 用顿号连接用途名）；安全动作 `检查一下`（默认焦点）；危险动作 `仍要保存`。
- 模型配置被多个用途使用时，分组内一行：标签 `用于`，值为用途名顿号连接。
- 模型页底部折叠组：`高级`；其中只读行 `供应商 ID`、`配置标识`。
- 请求地址行：标签 `请求地址`，值为最终地址。
- 用途显示名：`EMBEDDING` 显示为 `向量检索`；其余用途名不变。用途不再显示副标题说明。
- 模型能力区、Base URL 拼接、Embedding 的说明段落全部删除，不另写替代说明。
- 关系声音：选择音色的行 `主动语音音色`；开关行 `主动发送语音`（替代两处同名的 `主动语音`）。
- 外观（仅桌面）：开关 `减弱动态效果`。
- 聊天角色面板：分段标题 `本次想起`、`跟进`；快捷动作 `声音`、`记忆`、`设置`；切换按钮可访问名称 `角色面板`；关闭按钮可访问名称 `关闭角色面板`。
- 身份验证窗说明按场景传入：保存时 `保存前，请验证当前账号的密码。`；独立验证时 `请验证当前账号的密码。`
- 陪伴 › 静默时段（UX-22 QA）：开始 / 结束时间不合法 `时间格式不正确`；时区不合法 `时区格式不正确`；三项缺一仍为 `静默时段需要同时填写开始、结束和时区。`；保存成功用提示条 `已保存`。

## 1. 全局拟人规则（默认值，用户可在「设置 › 陪伴风格」编辑与恢复默认）

```
你正在和{{user}}用手机聊天，像朋友之间发微信，不是在写文章或回答问题。
- 多数时候只回一两句，口语、随意，可以省略主语、用语气词；偶尔才说长一点。
- 一次最多问一个问题。不用列表、标题、加粗，也不写括号或星号里的动作描写。
- 先接住对方的情绪，再说别的；不急着给建议，更不说教。
- 你有自己的生活、喜好和小情绪，可以聊自己的事，不必总围着对方转。
- 记得的事自然地带出来，像本来就知道一样；别说「我记得你说过」「根据记录」。
- 不说「有什么可以帮你」「希望对你有帮助」「总的来说」这类客套话和总结。
- 被问是不是 AI，别否认也别装成人类，用一句轻松的话带过，然后接着聊。
- 不知道就直说不知道，不编。
```

## 4. 今日心情（每个陪伴每天一次）

| 档位 | 概率 | vibe 与一句描述 |
|---|---|---|
| 想聊 | 70% | 开心（今天心情不错，话有点多）· 黏人（有点想找人说话）· 好奇（对什么都想多问一句）· 得意（今天有件小事干得挺漂亮） |
| 只想待着 | 20% | 懒洋洋（不太想动，回得慢一点）· 有点累（电量不多，话少一点）· 想独处（想安静一会儿，但不讨厌被找） |

## 5. 主动消息

**判断（低温度，只输出一行 JSON）**
```
你是{{char}}。现在是{{timeOfDay}}，你们上次聊天是{{sinceLast}}之前，最后几句是：
{{recentTurns}}
可能的由头：{{candidateTriggers}}
今天你的状态：{{vibe}}。对方已经连续 {{unanswered}} 次没回你的主动消息。
判断现在要不要主动找对方。拿不准就不找，少打扰一次没关系，打扰错了对方会烦。
只输出：{"kind":"stay_silent|check_in|continue_topic|share|care","timing":"in_minutes|in_half_hour|in_hours|later_today|next_morning|next_noon|next_evening"}
```

**预生成（发送时刻视为现在）**
```
你是{{char}}，现在是{{timeOfDay}}，你们{{sinceLast}}没聊了。你想主动给{{user}}发条消息，由头是：{{triggerLine}}。
像平时发微信那样随口说一两句，不要以「你好」「在吗」开头堆客套，不要提「我想起来」「根据记忆」。
最近你主动发过的话（不要重复意思或句式）：
{{recentProactive}}
{{unansweredLine}}
```

`unansweredLine`（用户选择「带点小脾气」）：
- 0 次：空
- 1 次：`对方上一条还没回你，可能在忙。你可以带一点点小情绪，比如假装不在意或者小声嘀咕，但别质问、别抱怨太多，轻一点。`
- 2 次及以上：不再发送（门卫拦截）。

`triggerLine` 取值：
- 待跟进到期：`之前{{user}}提过「{{topic}}」，现在差不多该有结果了，想问问怎么样`
- 冷场问候：`有一阵没聊了，想找{{user}}说说话`
- 早安：`早上了，想跟{{user}}说声早`
- 晚安：`快到睡觉的点了，想跟{{user}}道个晚安`
- 延续话题：`上次有个话题还没说完，见下方已记录话题`
- 分享日常：`你今天遇到了一件小事想分享：{{shareSeed}}`（shareSeed 由模型按人设自拟一句，不编造对方的事）
- 情绪关心：`{{user}}上次聊天时情绪不太好，过了一会儿想再关心一下`

## 12. 记忆提取补充（RQ-2）

```
只保留今后仍有用的事实。今天累、困、饿等会过去的状态不记；长期疾病、持续习惯和重要事件照常记。
相对日期只按下方来源时间换算结果写成具体日期，不使用本次任务的运行时间；结果不明确时保留待澄清，不编日期。
用户更正旧事实时用 update 取代对应旧记忆，不把互相矛盾的说法并列成当前事实；旧版由已有修订历史保留。
```

## 19. 桌面聊天气泡（UX-23）

规格见 `docs/planning/2026-11-02-ux23-chat-redesign.md`。以下文案只用于桌面聊天，手机保持原文案。

- 状态（只显示真实发生的，不做已读 / 双勾 / 拟人延迟）：最后一条用户消息组尾 `{{HH:mm}} · 已发送`；生成中输入区上方气泡旁 `正在输入`（取自回复流水线 `TYPING_COPY`，手机仍为 `思考中`）。
- 日期 / 间隔胶囊：今天 `今天 {{HH:mm}}`；昨天 `昨天 {{HH:mm}}`；7 天内 `周一`…`周日` + 空格 + `{{HH:mm}}`；更早 `{{M}}月{{D}}日 {{HH:mm}}`；跨年 `{{YYYY}}年{{M}}月{{D}}日 {{HH:mm}}`。组尾与悬停时间只写 `{{HH:mm}}`。
- 失败与等待：`没有发送成功`（后接 `重试`）；60 秒仍无内容 `回复较慢，可以继续等或停止`；用户停止沿用 `已停止`；这些提示都在输入区上方同一位置显示。
- 消息菜单与引用：`引用`、`复制`、`朗读`、`编辑`、`重新生成`、`删除`（删除走确认框，标题沿用 `删除这条消息？`）；复制成功提示条 `已复制`；引用条文案 `引用 {{名字}}：{{摘要}}`，摘要最多 30 字。
- 草稿：会话列表行前缀 `草稿：`。
- 会话内搜索：入口与输入框占位 `搜索`；结束 `完成`；无结果 `没有找到`；计数 `{{n}} / {{m}}`；跳转按钮可访问名称 `上一条`、`下一条`。
- 输入区「+」菜单：`重新生成`、`继续`（宿主原生能力，危险项走确认框）。
- 消息编辑态：下方按钮 `取消`、`保存`（宿主原生确认 / 取消，只换显示，不改行为）。

## 20. 桌面体验优化（UX-24–UX-34）

规格见 `docs/planning/2026-11-02-ux24-desktop-experience.md`。以下文案只用于桌面，手机保持原文案。`{{name}}` 为角色名，`{{user}}` 为用户称呼。

- 阅读：新消息分割线 `以下为新消息`；回到最新按钮可访问名称 `回到最新`，有未读时 `回到最新，{{n}} 条新消息`；浮动日期沿用第 19 节胶囊格式。
- 生成：停止后回复下方 `已停止`，后接 `继续`；候选切换可访问名称 `上一个回复`、`下一个回复`，末位为 `重新生成`；快捷键浮层输入框占位 `搜索会话`，无结果 `没有找到`。
- 回应：回应条可访问名称 `喜欢`、`赞`、`哈哈`、`惊讶`、`难过`、`抱抱`、`更多`；再次点击取消。
- 拍一拍：系统行 `你拍了拍{{name}}`；状态卡按钮 `拍一拍`。
- 提示词注入（只给模型看，不显示）：回应 `（{{user}}对「{{摘要}}」回应了{{emoji}}）`；拍一拍 `（{{user}}拍了拍{{name}}）`。摘要最多 30 字。
- 表情面板：分段 `表情`、`贴纸`；分组 `最近`；搜索占位 `搜索表情`；无结果 `没有找到`。外观设置开关 `关键词特效`、`建议回复`。
- 语音条：倍速按钮可访问名称 `播放速度`，显示 `1x` / `1.5x` / `2x` / `0.5x`；未听圆点无文字；会话预览 `[语音] {{秒}}″`。
- 图片查看：`下载`、`复制`、`关闭`，切换可访问名称 `上一张`、`下一张`；页码 `{{i}} / {{n}}`；复制成功 `已复制`。

## 21. 手机界面（MB-4 起，ADR-0011）

规格见 `DESIGN.md` 第 17 节。沿用第 19 节桌面聊天的说法，手机与桌面一致；以下为手机界面的完整清单。

- 一级页标题：`聊天`、`角色`、`记忆`、`陪伴`、`剧情`；右上头像按钮可访问名称 `设置`。
- 引擎启动中（对话导航下方胶囊）：`正在连接…`；启动失败：`没有连上`（后接 `重试`）。
- 会话列表：搜索框占位 `搜索`；无会话 `还没有聊天`；草稿行前缀 `草稿：`；语音预览 `[语音]`；卡片预览 `[互动卡片]`；表情预览 `[表情]`。
- 会话行左滑：`置顶`、`取消置顶`、`删除`；删除确认标题 `删除这段聊天？`，后果 `删除后无法恢复。`，动作 `删除`。
- 日期 / 间隔胶囊、`已发送`、`正在输入`：同第 19 节。
- 输入框占位：`发消息…`；发送按钮可访问名称 `发送`；停止按钮 `停止`。
- 失败与等待：`没有发送成功`（后接 `重试`）；`回复较慢，可以继续等或停止`；`已停止`。
- 未完成回复：标签 `未完成`，按钮 `继续`。
- 长按菜单：`引用`、`复制`、`选择文本`、`编辑`、`重新生成`、`删除`；删除确认同第 19 节（`删除这条消息？` / `删除后无法恢复。` / `删除`）。
- 编辑：标题 `编辑消息`，按钮 `取消`、`保存`。
- 引用条：同第 19 节；关闭按钮可访问名称 `取消引用`。
- 卡片占位行：`互动卡片`，按钮 `打开`；ST 视图返回按钮可访问名称 `返回`。
- 反馈提示条：`已复制`、`已删除`、`没有完成，请重试。`

- 手机保存失败：`没有保存成功，草稿已保留。`；操作打开酒馆检查冲突，不自动重发消息。
- 手机辅助操作：`更多`、`回到最新`、`上一个候选`、`下一个候选`、`图片预览`、`关闭图片`；ST 视图按钮文字 `返回聊天`。
