# 专属表情包生成说明（给 Codex 批量执行）

目标：为默认陪伴角色生成一套版权归 Owner 的中文聊天表情包，替代/补充内置的 Fluent Emoji。按本说明一次生成、自检、落盘，不需要 Claude 参与。

## 1. 角色设定（所有图保持一致）

- Q 版二头身女生，二十多岁的感觉，圆脸、大眼睛，表情夸张但可爱。
- 发型：栗棕色齐肩短发，右侧别一枚小小的黄色星星发夹（识别标志，每张都要有）。
- 服装：宽松的奶白色连帽卫衣，袖子稍长盖住半个手掌；下装可不画。
- 伙伴：一只橘白色小猫，只在部分表情里出现（见清单「猫」列）。
- 画风：干净的粗描边手绘贴纸风，柔和平涂 + 轻微高光，配色以奶白、栗棕、暖黄、浅粉为主；不要写实、不要 3D、不要复杂背景。
- 不得模仿任何现有动漫/品牌/明星形象。

## 2. 生成方法

1. 先生成一张**角色设定图**（正面、侧面、三个表情），定稿后作为后续每张图的参考图（image-to-image / reference），保证同一人。
2. 每张表情单独生成，构图：角色上半身或全身居中，四周留白约 8%，**透明背景**。
3. 文字：清单里有字的，字放在角色旁边或下方，圆润手写体，白色描边，2–6 个字，不要错字。
4. 每个标签至少 1 张、常用标签 2 张，共约 30 张。

提示词模板（按清单逐条替换 `{表情}{动作}{文字}{猫}`）：

```
chibi sticker of the same character as the reference sheet: young woman, chestnut-brown shoulder-length bob hair with a small yellow star hair clip on the right side, oversized cream-white hoodie with long sleeves; {表情}, {动作}{猫}; Chinese handwritten caption "{文字}" with white outline next to her; clean bold outline, soft flat colors, cute LINE-sticker style, transparent background, centered, no other background
```

## 4. 规格与落盘

- 尺寸：512×512 PNG，透明背景；另导出一份 256×256 缩略版放 `thumbs/` 同名。
- 目录：`integrations/sillytavern/extension/vc-model-settings/stickers/custom/`（缩略图在 `custom/thumbs/`）。
- 在同目录写 `manifest.json`（格式与 `stickers/builtin-manifest.json` 一致，图片路径相对 `custom/` 目录；扩展会自动加载这个包，不存在则跳过）：

```json
{
  "name": "专属表情包",
  "license": "Owner 所有",
  "attribution": "",
  "stickers": { "开心": ["开心-1.png", "开心-2.png"], "在吗": ["在吗-1.png"] },
  "kaomoji": {}
}
```

- 标签 `在吗`、`想你` 是新增的，需同时加入表情包标签表（`stickers.js` 的标签常量）。

## 5. 自检（每张都过）

1. 是同一个人：栗棕短发 + 右侧黄色星星发夹 + 奶白卫衣，三项都在。
2. 背景透明，四周没有白边或残留色块。
3. 文字与清单一致、无错别字、无多余文字或水印。
4. 表情一眼能看出对应情绪；缩到 128×128 仍能辨认。
5. 不像任何已有 IP 形象。
