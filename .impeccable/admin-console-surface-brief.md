# 后台控制台界面简报

- 范围：重做完整内部后台控制台；Operate 模式；桌面优先，同时支持移动端应急操作。
- 受众与任务：ADMIN/内部操作者快速确认 Go Runtime 的真实状态，查看提供方、模型和路由，并安全地暂存、检查、重新认证和应用变更。
- 主动作：检查本次变更并保存；次动作是刷新、发现模型、调整路由和放弃未保存变更。
- 内容证据：只读取当前 Go API 的真实返回；不展示 Java 时代已退役的账户、审计、队列、试用、邀请和工单能力；不生成假指标。
- 约束：简体中文；任何密钥保存后只显示“已配置”；不在日志、截图或界面回显凭据；所有交互目标至少 44px；错误、加载、空状态和无权限状态必须可见且可恢复。
- 视觉方向：Quiet Loom Control Room。固定侧栏、开放式账本、细分隔线、近白事实面；紫罗兰只用于当前选择和唯一主动作；不用卡片墙、长锚点页或模态表单。
- 记忆点：左侧是“当前生效配置”，右侧始终可见“本次变更”，让运行事实和待应用修改同时出现。
- 已批准参考：`.impeccable/mocks/decision/admin-change-ledger.png`，方案“变更账本工作台”，种子 `7b2f35e8`。
- 页面结构：运行总览、模型服务、路由策略、系统状态；旧 `/pages/ops/ops` 合并进新控制台。
- 未决项：无。总览由现有 Go 端点在前端聚合，不为展示新增无必要的后端聚合接口。
